# Assets

## Databricks logo

The landing page shows the official Databricks logo when this file exists:

    streamlit_app/assets/databricks-logo.svg   (preferred)
    streamlit_app/assets/databricks-logo.png   (fallback)

Download the official logo from Databricks' brand / press resources and save it
here with that exact filename. Do not recreate the logo by hand — use the
published asset so it matches Databricks' brand guidelines.

Until the file is added, the page falls back to a neutral placeholder mark.
On a white-on-dark panel, prefer a white/mono version of the logo.
